# Screens

## Implemented

### Home

Purpose: communicate value and offline/privacy positioning. Contains brand, headline, two disabled primary actions, an explicit next-phase notice and three trust points. Responsive from mobile to desktop. No menu or fake account identity.

## Planned MVP flow

Home → create/resume editor → personal info → summary → experience → education → skills → languages/courses → templates → preview → ATS Score → PDF/share.

My Resumes lists local documents and offers open, duplicate, rename and confirmed delete.

## Interaction principles

Large touch targets, explicit labels, predictable focus, meaningful empty states, few navigation levels and no required onboarding. Errors/status must not rely on color alone. Experience and education remain optional for first-job users.
